# Web de servicios digitales

Landing page estatica para ofrecer webs, apps, portfolios, cartas digitales, catalogos, turnos y sistemas simples para negocios.

## Deploy en Vercel

1. Importar el repositorio `nicodiax22/Flayer_freelance` en Vercel.
2. Framework preset: `Other`.
3. Build command: dejar vacio.
4. Output directory: dejar vacio o `./`.
5. Deploy.

El sitio usa HTML, CSS y assets estaticos, sin backend.
